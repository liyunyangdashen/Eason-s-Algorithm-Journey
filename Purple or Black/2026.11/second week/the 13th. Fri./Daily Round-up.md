## 二、主线攻坚：P11383 公平分配

### 1. 题目与困难

两个人对同一批物品有不同的价值判断，分别使用：

\[
a_i,\quad b_i
\]

目标是构造一个让双方满足题目公平条件的分配。

最初遇到的困难是：

- 物品可以分配到任意集合，不要求连续。
- ST 表、线段树等区间查询结构并不直接适用。
- 两个人的价值体系不同，不能只比较同一种价值。
- 需要同时保证双方的公平性。

### 2. 最终算法

先根据第一人的价值 \(a_i\) 降序排列物品。

准备两个临时集合 X、Y，分别维护两种价值之和。

处理第 \(i\) 件物品时：

- 比较 X 和 Y 当前的 \(a\) 价值之和。
- 将物品放入 \(a\) 价值之和较小的集合。
- 同时累计两个集合的 \(b\) 价值。

所有物品分配完毕后，根据两个集合的 \(b\) 价值总和，决定最终由谁拿哪一堆。

### 3. 核心证明

排序后，每次新加入的物品都是当前已处理物品中价值最小的。

当它被放进当前总价值较小的集合时，可以维持两堆在第一人价值视角下的双向公平条件。

因此，无论最后如何交换两堆，第一人的公平性都能保持。

第二人则获得自己评价总价值较高的那一堆，因而不会嫉妒另一堆。

**核心突破：先构造一种价值体系下的双向公平划分，再通过交换解决另一种价值体系。**

### 4. 代码实现亮点

采用：

```cpp
using pll = pair<ll,ll>;
pll v[N],sx,sy;
int id[N];
bool gv,hv[N];
```

通过 `id[]` 排序而不直接修改原始物品数据：

```cpp
sort(id + 1,id + n + 1,[](int x,int y){
    return v[x].first > v[y].first;
});
```

最终使用：

```cpp
gv = (sx.second >= sy.second);
```

并通过：

```cpp
hv[i] ^ gv
```

完成最终分配方向的切换。

这是本题非常简洁的实现技巧。

**复杂度：**

\[
T=O(n\log n),\qquad S=O(n)
\]

## 三、基础算法与代码排错

### P5788：单调栈

**成绩：4 分钟 AC。**

采用从右向左扫描的单调栈：

```cpp
while (!s.empty() && a[s.top()] <= a[i])
    s.pop();
```

栈内保存下标。

当前栈顶就是右侧第一个严格大于当前元素的位置。

训练成果：

- 正确掌握严格大于条件。
- 熟练使用下标栈。
- 实现时间达到快速模板题水平。

复杂度：

\[
O(n)
\]

### P1738：洛谷的文件夹

**成绩：AC。**

采用以字符串为键的目录树：

```cpp
struct treenode{
    string nm;
    map<string,treenode*> mp;
};
```

每个目录节点维护它的直接子文件夹。

处理一条路径时，逐段解析文件夹名称。若当前节点中不存在对应子目录，就新建节点并将答案加一。

核心收获：

**Trie 不一定以单个字符为边，也可以按整个字符串分段建立树形结构。**

调试中还发现，分隔符 `/` 被保留进下一段目录名称。虽然在这一实现中使用一致的编码方式并最终 AC，但分割逻辑仍可以写得更清晰。

### P3111：Cow Jog S

**成绩：AC。**

第一次尝试使用从左到右的相邻最终位置比较：

```cpp
if (p[i] > p[i - 1])
    ans++;
```

问题在于：相邻位置关系不足以确定最终分组，因为前方可能已经形成一个更大的牛群。

修正为从右向左扫描，维护前方各组的最小最终位置：

```cpp
for (int i = n;i >= 1;i--)
    if (p[i] < minn)
        ans++,minn = p[i];
```

同时使用 `long long` 保存：

\[
p_i=x_i+v_iT
\]

核心错因：

**局部相邻比较不能代替对前方整体状态的维护。**

这是一道很有价值的贪心反例训练题。

复杂度：

\[
O(n)
\]

## 四、尚未完成的题目研究

### P2080：增进感情

首先使用 DFS，枚举每件事选择或不选择。

模型中维护：

\[
S_A=\sum a_i,\qquad S_B=\sum b_i
\]

并尝试最小化：

\[
|S_A-S_B|
\]

发现的问题：

1. 初版使用 `suma+sumb > k`，需要特别核对题目是否允许恰好达到阈值。
2. DFS 需要枚举 \(2^n\) 个子集，数据规模较大时可能超时。

随后讨论了利用总和与差值重新定义状态的 DP 思路。

但当天没有完成最终 DP 程序，因此此题仍处于研究阶段。

### P1011：车站

使用系数分解处理未知上车人数。

将每站人数表示为：

\[
u_i=\alpha_i a+\beta_i b
\]

其中两个系数序列分别按照斐波那契式递推。

通过已知车站人数建立方程，反求未知参数。

这道题的主要收获是：

**遇到含未知初始条件的线性递推，可以将结果拆成不同初始变量的系数之和。**

需要继续关注特殊站点和分母为零等边界情形。
